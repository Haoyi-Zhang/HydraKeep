# Heterogeneous transaction profile

This profile was fixed before executing its browser matrix. It applies the same
transaction-indexed contract to a text input, a Boolean checkbox, and a single
select. The observer records typed live properties (`value` or `checked`), not
HTML attributes. Each React workflow has a paired Vue implementation.

The eight workflow contrasts are: immutable snapshots; a deferred read of live
state; Boolean-to-string payload coercion; a clean scoped identity save followed
by consent save; an overbroad clear of the unconsumed checkbox; a permitted
select reset followed by a new edit; a stale payload after that reset; and a
physical replacement of the text node that preserves logical identity and value.
Two edit placements, two dispatch orders, and two repetitions are crossed. These
are authored method controls, not independent production applications or newly
discovered framework defects.

The profile tests three information requirements that the text-only study cannot
separate: typed equality at the receiver, logical rather than physical node
identity, and field-scoped release across heterogeneous controls. Browser actions
are ordinary Playwright keyboard, checkbox, and select actions. Every consumption
must have one actual loopback HTTP record matched by transaction identity.
